# Онлайн-сервіс бронювання спортивних залів та секцій

Курсова робота з дисципліни
«Документування програмного забезпечення та шаблони проєктування».

Варіант 1.

## Призначення

Вебзастосунок для мережі спортивних центрів, який забезпечуватиме
перегляд залів, секцій і тренерів, бронювання послуг,
управління абонементами та взаємодію з клієнтами.

## Заплановані можливості

- Каталог залів, секцій і тренерів із фільтрацією.
- Реєстрація, вхід та особистий кабінет.
- Бронювання залу або місця на занятті.
- Підтвердження бронювання та імітація оплати.
- Разові, місячні та корпоративні абонементи.
- Стандартні, преміум і корпоративні картки клієнтів.
- Бонусні бали та персональні пропозиції.
- Сповіщення і нагадування.
- Адміністративна панель.
- REST API.

## Заплановані технології

Python, Django, Django REST Framework, SQLite,
HTML, CSS, JavaScript.

## Стан проєкту

Підготовлено віртуальне середовище Python.
Проєкт перебуває на етапі аналізу вимог і проєктування.

Інструкцію запуску буде додано після створення застосунку.
